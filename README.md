# 📊 Customer Feedback Sentiment Analyzer

An AI-powered web application built with **Streamlit** and **TextBlob** that analyzes customer feedback and reviews in real-time. It predicts whether a review is Positive, Neutral, or Negative and provides data visualization for bulk reviews.

---

## ✨ Features

* **Single Review Analysis:** Instantly analyze the sentiment and polarity score of individual customer reviews.
* **Bulk CSV Upload:** Upload a dataset (`.csv` file) containing multiple reviews for batch sentiment analysis.
* **Data Visualization:** Generates a clean Pie Chart showing the overall distribution of positive and negative sentiments.
* **Interactive UI:** Simple and user-friendly interface built using Streamlit.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Frontend/Framework:** Streamlit
* **NLP Library:** TextBlob
* **Data Processing:** Pandas
* **Visualization:** Matplotlib
